# Security Policy

Nexo Mechanics follows OWASP-based security practices across all projects, including automated security scanning, secure credential handling, and access control review.

## Reporting a Vulnerability

**Email:** mail@nexomechanics.com  
**Subject:** `[SECURITY] <brief description>`

We aim to respond within 48 hours. Please do not disclose publicly until we have addressed the issue.

## Scope

This policy applies to all Nexo Mechanics repositories and services.
